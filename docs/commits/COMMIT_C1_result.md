§4① 사전 약정에 따른 β중립 12-0 참고 실행(1회)의 결과를 기록한다. 판정은 **미관찰 → 종료**다.

| 기준 | 문턱 | 결과 | |
|---|---|---|---|
| C1 2009 반등 | Δ ≥ +5.0%p | +29.0%p | 통과 |
| C1 2018 하락 | Δ ≥ +5.0%p | +0.3%p | **미달** |
| C2 나머지 9구간 | 중앙값 ≥ −2.0 · 최악 ≥ −10.0 | +0.1 · −4.5 | 통과 |

미달한 두 기준은 서로 독립이고, 둘 다 문턱과 차이가 크다. 경계선 판정이 아니다. C1 을 "둘 중 하나만 통과"로 느슨하게 읽어도 C3 에서 종료된다.

A/B 장부 · 랭킹 규칙 · 필터 · 트리거 숫자는 하나도 바꾸지 않았다(§5). 라이브 동작도 변경이 없다.
