## 설계 근거 — 채택한 선택지

| 결정 | 채택 | 근거 |
|---|---|---|
| 임계값 | **2** | 효과가 가장 뚜렷. 상수 하나라 3 으로 변경 용이 |
| 앱 적용 | **표시만** | 앱=탐색, 메일=실행. 배너가 없으면 "메일은 없는데 앱엔 신호"가 설명 안 됨 |
| 2pm 장중 | **미적용** | 장중은 raw truth 반영이 설계 철학. 또한 `market_warnings` 는 당일 종가를 포함(shift 없음)하므로 미완성 봉에서는 5pm 과 다른 값이 나온다 |

실적 게이트에서 검증된 **동결(freeze)** 을 그대로 재사용한다.

## 이관 중 발견한 버그 (수정하지 않음 — 별건)

원본 `_market_warnings` 의 `w.fillna(2.0)` 은 **죽은 코드**였다.

```python
(c < ma200).astype(float)   # ma200 이 NaN → (NaN < NaN) = False → 0.0
```

비교 연산이 NaN 을 `False` 로 삼키므로 `w` 에는 NaN 이 생기지 않는다. 즉 원본 주석의
"지표 산출 전 구간은 중립(2)" 은 사실이 아니며, 실제로는 **경고 0개(=최대 관대)** 였다.
백테스트 워밍업 구간(첫 ~200봉)에서 게이트가 전혀 작동하지 않았다는 뜻이다.

과거 측정치와의 비교 가능성을 지키기 위해 `fill_neutral` 경로에서 이 동작을 그대로 보존했다.
수정하려면 백테스트를 전량 재실행해야 하므로 별건으로 분리한다.
라이브 경로(`fill_neutral=None`)는 명시적 NaN 마스킹을 적용해 fail-open 판정이 가능하다.

### 테스트 작성 중 겪은 함정 (기록)

1. **`__pycache__` 스테일** — 뮤테이션이 `"Y"`↔`"N"` 처럼 **같은 바이트 길이**면 mtime+size 기반
   pyc 무효화를 통과해 **복원 후에도 변조된 바이트코드가 실행된다.** 실제로 거짓 실패가 1회 발생했다.
   → 뮤테이션 하네스는 `PYTHONDONTWRITEBYTECODE=1` + `rm -rf __pycache__` 필수.
2. **문자열 검사로는 결선을 못 잡는다** — `"mkt_gate=" in src` 는 `mkt_gate=None` 으로 바꿔치기해도
   통과한다. `"_mkt_users" in func_src` 도 상단 대입문 때문에 통과한다. 세 항목(게이트 미결선 /
   토글 무시 / 호출부 전달 누락)이 실제로 미검출됐고, **AST 로 인자 값이 `Name` 노드인지,
   조건식 안에 검사가 들어있는지**까지 확인하도록 강화한 뒤에야 잡혔다.
3. **합성 상승장은 경고 0개가 아니다** — 랜덤워크는 우상향이어도 50일선 하회 + 20일 수익률
   마이너스로 경고 2개가 쉽게 뜬다. 결정론적 단조 상승(`100 × 1.0005^i`)이 필요했다.
   이것 자체가 **임계값 2 의 차단률이 21% 인 이유**를 설명한다.
