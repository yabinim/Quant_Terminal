# feat(reminders): 개발 로드맵 리마인더 + 매도 사유 태그

"3개월 뒤 다시 본다"로 미뤄둔 항목을 매일 메일로 되살린다.
그리고 매수에만 있던 사유 태그를 매도에도 붙인다.

⚠️ **C블록(내부자) 건과 함께 올린다.** `app.py` 가 양쪽에 걸쳐 있다.

| 2 | 수신 대상 | **A. 관리자 전용** — `Users` 열 추가 없음 |

**1번을 매매 레이더가 아니라 내러티브로 정한 이유** — 레이더는 발동 건이 없으면
메일 자체를 생략한다(`run_watchlist_alerts.py:421`). 만기 알림이 "그날 매매 신호가
있었는가"에 좌우되면 하필 조용한 날 만기를 통째로 놓친다.

**2번은 다중 사용자 원칙의 의도적 예외다.** 근거는 콘텐츠 성격이 관리자 전용
개발 로드맵이라는 것이고, `Narratives`·`DRG` 와 같은 취급이다. 현 스키마는
나중에 `Alert_Reminder` 열을 더해 사용자별로 확장하는 것을 막지 않는다.

## 변경 파일

### 신규 `reminders_core.py` (231줄) — SSOT

`gspread` 를 import 하지 않는 순수 모듈이다. 시트 접근은 호출부 책임이다.
`app.py` 와 `run_narrative.py` 가 **같은 함수로 만기를 판정**한다 —
앱에선 '오늘 만기'인데 메일엔 안 오는 불일치가 나면 안 된다.

시트 `Reminders` 10열:
`ID · Due_Date · Title · Category · What_To_Check · Why · Status · Snoozed_Until · Created · Source`

핵심 설계 셋:
- **`Snoozed_Until` 이 `Due_Date` 를 이긴다.** "봤지만 아직 못 함"을 `done` 으로
  처리하면 항목이 영영 사라진다
- **만기 파싱 실패는 `overdue`** 로 띄운다. `later` 로 숨기면 영원히 안 보인다
- **띄울 게 없으면 빈 문자열**을 반환한다. 매일 "리마인더 없음"이 붙으면
  블록 자체를 안 읽게 되고, 정작 만기가 왔을 때도 안 읽는다

### `run_narrative.py` (932 → 933, +1 수정)

`_reminder_block_html()` 추가. 관리자가 수신 대상일 때만 시트를 조회하고,
발송 루프에서 관리자에게만 본문에 덧붙인다.

**실패해도 브리핑 발송을 막지 않는다.** 시트 하나 못 읽었다고 그날 브리핑이
통째로 안 나가면 손해가 훨씬 크다. `WorksheetNotFound` 는 경고도 내지 않는다
(아직 시트를 안 만든 정상 상태다).

### `app.py` (25992 → 26205, +213)

**리마인더 UI** — 👑 [관리자] 유저 승인 탭 상단. 완료 / +7·+14·+30일 연기 /
새 항목 추가. 예정·완료는 접힌 영역에.

**매도 사유 드롭다운** — 7종. 시스템 판정이 매도/주의면 "🔴 매도 신호"가
기본 선택된다. 판정은 포트폴리오 표에서 이미 계산한 `_card_status` 를 재사용해
추가 조회 비용이 0이고, 표·카드와 같은 SSOT 를 쓴다.

memo 형식: `[매도:⚖️ 리밸런싱] [판정:🔴 매도] 분기 조정`

**두 태그를 분리한 것이 핵심이다.** `[매도:]` 는 왜 팔았나(사용자),
`[판정:]` 은 무엇이 사실이었나(시스템). 둘이 어긋난 경우가 실행 갭이고,
그게 2027년 2월 평가에서 제일 보고 싶은 정보다. 하나로 뭉개면 사라진다.

`_SSOT_NEEDS` 에 `reminders_core` 등록 — 락스텝이 깨지면 페이지 중간
`AttributeError` 대신 시작 시 경고가 뜬다.

### 신규 `automation/seed_reminders.py` (148줄)

초기 3건 적재. 앱에서 손으로 치면 `What_To_Check` 가 "내부자 블록 확인"
한 줄로 줄어들고 3개월 뒤엔 무슨 뜻인지 모르게 된다.

멱등하다 — ID 가 같으면 덮어쓰되 **기존 `Status`/`Snoozed_Until` 은 보존**한다.
재실행이 완료·연기 처리한 항목을 되살리면 안 된다.

## 남은 한계

- 리마인더는 관리자 전용이다. 게스트용 개인 리마인더가 필요해지면
  `Users` 에 `Alert_Reminder` 열을 더해 확장한다

  2027년 2월 평가는 오늘 이후 데이터만 대상이다
- 시스템 판정 기본 선택은 `_card_status` 가 계산돼 있을 때만 동작한다.
  포트폴리오 표 계산이 실패한 세션에서는 "🧩 기타 / 미지정"이 기본값이 된다
  (틀린 라벨이 자동으로 박히는 것보다 낫다)
