## 1. C-축소 — AI 탭 4 → 2

### 4개를 하나로 묶지 않은 이유

| 탭 | 목적 | 데이터 소유권 |
|---|---|---|
| 적중률 트래커 | AI가 얼마나 맞혔나 | **shared** (`_shared_owner_uid`) |
| Emerging 추적기 | AI가 무엇을 반복 지목했나 | **shared** |
| Idea-to-Portfolio | AI 아이디어 → 내 편입 | **personal** |
| 주간 요약 | 내 포지션 종합 리뷰 생성 | personal(+narratives) |

넷을 한 탭에 넣으면 **한 화면 안에서 소유권이 갈린다.** 게스트에게는 위 절반이
관리자 결과, 아래 절반이 자기 데이터가 된다. 공통점이 `[AI]` 접두뿐인 통합은
목적 기준이 아니다.

**결정적 근거**: 게스트 안내표(`app.py` 3,131~3,151)가 이미 같은 선을 긋고 있었다.

```
## 🟢 자유롭게 사용하는 탭 (내 데이터로 저장됨)
  ... 💡 Idea-to-Portfolio 추적 / 📋 주간 포트폴리오 요약
## 🔵 열람 전용 탭 (자동으로 매일 갱신)
  ... 📊 적중률 트래커 · 📡 Emerging 종목 추적기
```

앱 자체 문서가 2-2 로 나눠놓은 것을 탭 구조가 따라가지 못하고 있었다.

### 결과

| 신규 탭 | 구성 | 줄수 |
|---|---|---|
| `📊 [AI] 내러티브 성과` | 🎯 적중률 트래커 / 📡 Emerging 추적기 | 635 |
| `💡 [AI] 내 포트폴리오 리뷰` | 💡 Idea-to-Portfolio / 📋 주간 요약 | 317 |

상수 `NAV_HITRATE`·`NAV_IDEA`·`NAV_WEEKLY`·`NAV_EMERGING` → `NAV_AIPERF`·`NAV_AIREVIEW`.
`_MAIN_NAV_OPTIONS`·`_NAV_GROUPS` 동시 갱신.

### 문서 동기화

- 게스트 안내표 2행 → 1행 병합, 열람 전용 목록 갱신
- 사용 가이드 expander 4개 라벨을 `상위탭 → 구획` 형태로 변경
  (예: `📊 **[AI] 내러티브 성과 → 적중률 트래커**`). 내용은 그대로 유효하다 —
  기능이 사라진 게 아니라 상위 탭만 바뀌었다.

## 3. 부수 발견 — saved_price 복구가 두 벌이다

같은 탭에 술어가 **완전히 동일한** 복구 기능이 두 곳 있다.

```python
# 24839
_missing_sp   = [i for i in wl_items if pd.isna(pd.to_numeric(i.get("saved_price"), errors="coerce"))]
# 25673
missing_price = [i for i in wl_items if pd.isna(pd.to_numeric(i.get("saved_price"), errors="coerce"))]
```

830줄 떨어져 있어 서로의 존재를 모르고 각각 자란 것으로 보인다. 이번에는 **둘 다
`✏️ 등록·관리` 로 옮기기만 했다** — 통합은 동작 변경이라 별도 건으로 남긴다.
이제 한 화면에 나란히 있으므로 차이를 눈으로 확인할 수 있다.
