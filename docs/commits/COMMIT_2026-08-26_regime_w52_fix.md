## 작성 중 X 그룹이 잡아낸 결함 1건 — 기록

**초안의 구조 탐지기가 아무것도 잡지 못했다.** X4 가 발견했다.

`windowed_names` 초안 규칙이 "식 안에 `Subscript` 가 있으면 창을 거친 것"이었다.
그런데 `close = pd.to_numeric(hist["Close"], ...).dropna()` 의 `hist["Close"]` 가
`Subscript` 다. → **`close` 자신이 안전 목록에 들어가** 옛 코드의 `close.max()` 를
한 건도 못 잡았다. **R1 의 '0곳'도 같은 이유로 잘못 통과하고 있었다.**

→ 컬럼 선택(문자열 상수 첨자)과 행 슬라이싱(슬라이스·불리언 마스크)을 구분하도록
규칙을 좁히고, 판별 케이스 S12·S13 을 신설했다.

**X 그룹이 없었다면 이 가드는 영원히 초록불인 채 아무것도 안 지켰을 것이다.**
