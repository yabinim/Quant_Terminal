```

  미검증 — 수익률 검증 없음. 사실 표시이며 매수·매도 신호가 아닙니다.
  ┌──────────────────────────────────────┐

  │ 분기 가중평균 주식 수(basic) · 분할 조정 반영본  │
  └──────────────────────────────────────┘
```

- **데이터 경로는 사전약정 §2 와 동일** — `income-statement?period=quarter` 의
  **basic** `weightedAverageShsOut`. diluted 는 옵션 회계 가정이 섞여 쓰지 않는다.
  이 필드는 분할 조정이 끝난 값이라(Phase 0 I-ARTIF 0.74%) 별도 보정이 없다.
- 기존 `_fmp_income_series()`(캐시 1시간, `_fmp_ui_get` → `fh.fmp_get_ex`) 재사용.
  **신규 fetch 함수 없음 · A1 래칫 영향 0.** 정밀검사 1회당 최대 +1 FMP 콜.
- `limit=4` 를 쓰는 기존 호출부(QoQ EPS 폴백)는 **건드리지 않았다.** 캐시 1콜을
  아끼려고 계약이 다른 소비자 둘을 한 키로 묶는 결합도가 1콜보다 비싸다.
- ETF 는 구조적으로 이 블록에 닿지 않는다(`is_etf_mode` 의 `else:` 안). ETF 의 주식
  수 변동은 설정/환매 flow 이지 희석이 아니다(§1).
- 정렬을 FMP 응답 순서에 맡기지 않는다 — 날짜 기준 내림차순으로 **직접 정렬**한다.
- 5분기 미만이면 **숫자를 만들지 않고** 부족 개수를 밝힌다.
- 두 기준 분기 간격이 300~430일을 벗어나면(분기 보고 누락) "12개월이 아니다"를 명시한다.
- `|변화| > 100%` 면 "합병·대규모 발행 가능성"을 **주석으로** 붙인다(판정이 아니다).
- 조회 실패는 캡션 한 줄로 강등 — 이 블록 하나 때문에 ③ 탭 나머지가 죽지 않는다.

블록 위에 **17줄짜리 경고 주석**을 붙였다. §9 종료 근거, §7 세 조건(①수익률 주장 금지
②미검증 문구 명시 ③점수·신호·배지 연동 금지), 그리고 *색으로 호·불호를 칠하는 것도 ① 위반*
이라는 점을 적었다. PEAD 에서 실패한 것은 신호가 아니라 예측을 주장하는 배지였다.

  분기 보고 기준이므로 자사주 매입 발표 직후에 즉시 반응하지 않는다.

  ±100% 주석은 "M&A 규모"를 가릴 뿐 M&A 여부를 판정하지 않는다(§4).
- 정밀검사 1회당 최대 +1 FMP 콜(1시간 캐시). 같은 종목을 반복 조회해도 1콜이다.

  `expanded=True` 한 글자로 바꿀 수 있다.
- **이 수치를 Fundamentals Score·스캐너·워치리스트 배지로 끌고 가려면 새 사전약정이 먼저다.**
