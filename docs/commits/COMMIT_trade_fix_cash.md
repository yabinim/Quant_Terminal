fix(portfolio): 거래 정정·계좌 이동 시 현금 잔고 복원 + DIV 정정 수량 오염 버그 수정

## 배경
매수·매도·배당은 기록할 때 계좌 현금을 자동으로 움직입니다. 그런데 🩹 거래 기록 정정은
원장과 수량만 되돌리고 현금은 그대로 뒀습니다. 조사 중 두 가지를 더 발견했습니다.

1. **DIV 정정 버그**: 정정 코드가 `if BUY … else: # SELL 취소` 구조였습니다. 그래서 현금 배당(DIV) 행을
   되돌리기 켠 채 정정하면 SELL 분기로 떨어져, **보유 수량에 보유주수가 더해졌습니다.**
2. **배당 정정이 막다른 길**: 원장을 지워도 `Dividend_Log`에 '처리됨'이 남아 그 배당이 다시 뜨지 않았습니다.

## 원칙 — 정정 = "그 거래가 없었던 상태"
| 원장 행 | 기록 시 현금 | 정정 시 현금 |
|---|---|---|
| BUY | −수량×가격 | +수량×가격 |
| SELL | +수량×가격 | −수량×가격 |
| DIV (현금 배당) | +배당액 | −배당액 (수량 불변) |
| BUY `[배당재투자]` | 순 0 (입금 + 매수) | 0 |

## 파일별 변경 — app.py (단독)

### 신규 헬퍼 (모듈 레벨, `update_trade_history_account` 직전)
- `_ledger_cash_effect(action, shares, price, memo)`
  - 원장 한 행이 기록될 때 현금에 준 영향. 정정과 계좌 이동이 함께 쓰는 SSOT
  - 기록 경로의 실제 동작을 1:1로 옮김
- `_ledger_dividend_ex_date(memo)`
  - 배당 태그가 있는 행에서만 `배당락 YYYY-MM-DD`를 추출
- `delete_dividend_log_rows(uid, account, ticker, ex_date)`
  - (ID, Ticker, Ex_Date) + Account가 일치하는 행을 삭제
  - 계좌 일치가 없으면 **정확히 1건일 때만** 삭제 (계좌 이동 후 로그가 옛 계좌로 남은 경우)
  - 2건 이상 모호하면 지우지 않고 알림
  - 캐시 미사용, 내림차순 삭제

### 🩹 거래 기록 정정
- DIV 행은 수량 체크박스를 보여주지 않음 (`_tf_undo=False` + 안내 문구)
- `else:` → `elif _tf["action"] == "SELL":` 로 바꿔 알 수 없는 액션이 SELL로 떨어지지 않게 함
- **현금 되돌리기 체크박스** (수량 체크와 별개, 기본 켬, 거래마다 키 분리)
  - 미리보기: `계좌: $현재 → $이후 (±금액)`
  - 음수가 되는 경우 경고 표시
- 재투자 BUY는 "현금 변동 없음" 안내
- 배당 행은 "배당 처리 기록도 지워 미처리로 복귀" 안내
- **실행 순서**: 원장 삭제 → 포트폴리오 → 배당 로그 → **현금 (마지막)**
  - 원장 삭제 뒤로는 재시도가 불가능. 현금이 손으로 고치기 가장 쉬운 한 칸이라 맨 뒤에 둠
  - 실패하면 직접 수정할 정확한 금액을 표시
- 성공 메시지를 `_esc_md`로 감쌈 (금액이 2개 이상일 때 LaTeX로 해석되는 문제 방지 규약)

### 🔀 계좌 이동
- **현금도 함께 옮기기 체크박스** (기본 끔, src·ticker·dst 조합마다 키 분리)
  - 미리보기는 원장의 순현금흐름: 원계좌 −E / 대상계좌 +E
- 현금 이동은 **원장 이관 성공 직후에만** 실행
  - 금액은 방금 읽은 원장으로 다시 계산
  - 재시도하면 원장 행이 이미 넘어가 있어 이중 이동이 없음
- 원계좌에서 실패하면 대상계좌는 건너뛰고, 두 계좌에 직접 수정할 금액을 모두 표시
