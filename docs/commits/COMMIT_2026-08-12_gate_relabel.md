## 배경

`Signal_Backtest` 시트 실측 결과, R:R 게이트의 `skip` 판정이 억제 근거를 갖지 못한다는 것이
확인됐다. 개별주(`Segment=stock`) 기준 중복 run 제거 후 **8개 독립 측정 전부**에서 방향이 동일했다.

판단 근거는 **SPY 초과수익이 아니라 MAE** 다. 초과수익 차이(≈0.0~0.1%p)는 N≈535 기준
표준오차 안이라 통계적으로 무의미하다. 그러나 게이트의 명분인 '손실 방지'의 직접 지표인
최대 불리 편차(MAE)가 `pass` 쪽이 일관되게 **더 깊다**. 손실 방지 필터가 하락폭을 키우고
있으면 그 필터는 목적을 달성하지 못한 것이다.

또한 8개 run 전부에서 `alert_entry_na = 0` 이 나왔다. `resolve_target` 이
(최근고점 − 진입) < 1R 일 때 목표를 `rr_derived` 로 폴백하는데, 이 경우 R:R 이 자기참조라
게이트 필터로 쓰이지 않으면서도 `gate` 는 `"fit"` 이 된다. 즉 **전고점 코앞이라 R:R 을
측정조차 못 한 건이 전부 `alert_entry_pass` 로 흡수**되어 pass 버킷이 오염돼 있었다.

## 변경 내용

### 1. `regime_core.py` (SSOT)

- **`GATE_LABELS["skip"]`**: `"⚠️ 자리 나쁨 — 건너뛰기"` → `"ℹ️ 고점 근접 — 참고"`
- **`build_watchlist_plan`** skip 분기: `enter_ok` 를 `False` → **`True`**,
  `gate_reason` 을 `"R:R … — 손익비 부족"` → `"전고점까지 여력 1:X (목표 1:Y 미만)"`.
  판단 근거를 주석으로 코드에 남김.
- **`buy_decision`**: `entry` + `skip` 일 때 `wait_pullback`/`wait_range` 로 강등하던 로직 제거
  → `"buy"`. `avoid` 강등은 그대로 유지.
- **`decorate_entry_alert`**: `skip` 을 통과 분기로 이동하고 전용 라벨
  `"🟢 매수 신호 (ℹ️ 고점 근접 구간)"` 부여. 손절·목표·R:R 숫자 라인은 그대로 유지.
- `else` 분기가 avoid/caution 전용이 되었으므로 잔존 skip 어휘 제거:
  `"⛔ 매수 신호 — 회피 구간"` / `"⚠️ 매수 신호 — 신중(분할·관망 고려)"` 로 분리.
- 관련 docstring 2곳 갱신.

### 2. `app.py`

## 설계 근거 — 기각한 대안

| 대안 | 기각 사유 |
|---|---|
| **게이트 완전 제거** | 측정 기간(2022-06~2026-07)이 대부분 상승장이고 FMP 5년 롤링 제한으로 2018·2020 검증 불가. `skip` 이 상승 국면에 편중돼 발생한다는 해석이 맞다면 **하락장에서 부호가 뒤집힐 수 있다.** 라벨·버킷은 유지해 계속 측정한다. |
| **`rr_derived` 폴백을 `gate="na"` 로 라우팅** (직전 세션 제안) | **철회.** `gate=="na"` 는 앱에서 '플랜 없음'으로 취급된다 — `app.py` L583 `compute_auto_plan_for_holding` 이 `None` 을 반환해 매수 완료 후 포트폴리오 등록 시 자동 플랜이 사라지고, L22705 워치리스트 표시가 한 줄로 축약돼 손절·목표·수량이 사라지며, L19690 분기도 바뀐다. 멀쩡한 플랜을 '플랜 없음'으로 만드는 부작용이 크다. → **측정 문제이므로 버킷터에서만 해결.** |
| **`decorate_entry_alert` 조건만 완화하고 `buy_decision` 유지** | 이메일은 '매수 신호', 앱 매수 카드는 '눌림목 대기' 로 갈라진다. 이번 조사에서 문제가 된 앱↔이메일 불일치 패턴을 그대로 재생산. |
| **`regime_params` 가변 ATR 배수 제거** | 별건으로 분리. 미검증인 것은 맞으나 반증된 것은 아니고, 이번 변경과 효과가 섞이면 원인 분리가 불가능하다. |

회귀 스위트가 실제로 `entry`/`wait` 게이트 분기를 타는지 확보하기 위해 seed×gap×rr_target
탐색을 넣었다. 합성 데이터는 대부분 `overheat`/`trend_break` 로 판정되어, 단순 고정 파라미터로는
게이트 분기를 통과하지 못하고 테스트가 조용히 통과해버린다(초기 2회 실패로 확인).

실측 검증 시나리오: `seed=2 gap=0.08 rr_target=2.0` → R:R 1:1.8, `target_basis=structural_high`
→ `gate=skip`, `enter_ok=True`, 라벨 `🟢 매수 신호 (ℹ️ 고점 근접 구간)`.
